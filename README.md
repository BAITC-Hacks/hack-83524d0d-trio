# Студенческий бюджет

Адаптивное веб-приложение для личного учёта студенческих расходов. Интерфейс полностью на русском языке, валюта — тенге (₸).

## Запуск

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

После запуска Vite покажет локальный адрес приложения. Для проверки production-сборки:

```bash
npm run build
```

## Возможности

- Выбор месяца и мгновенный пересчёт всей аналитики.
- Карточки: расходы за сегодня, итог месяца, самая затратная категория и количество записей.
- Добавление расхода с суммой, категорией, датой и необязательным описанием.
- Понятная проверка обязательных полей и положительной суммы.
- Список расходов только за выбранный месяц и подтверждение перед удалением.
- Сводка по категориям: суммы, проценты и цветные полосы прогресса.
- Сохранение расходов в `localStorage`, поэтому записи остаются после перезагрузки страницы.
- Три демонстрационные записи для текущего месяца при первом открытии: Еда — 1 500 ₸, Транспорт — 600 ₸, Еда — 900 ₸. Их итог — 3 000 ₸.
- Адаптивная вёрстка для компьютеров и телефонов.

## Ограничения

- Данные хранятся только в браузере на этом устройстве; синхронизации, аккаунтов, сервера и базы данных нет.
- Очистка данных сайта в браузере удалит сохранённые расходы.
- Приложение предназначено для учёта расходов, а не доходов или финансового планирования.
